# Exploratory Data Analysis (EDA)

## 📌 Objective
To understand the dataset by exploring its structure, patterns, trends,
relationships, and potential data quality issues before further analysis.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 🔍 EDA Steps Performed
1. Asked meaningful questions about the dataset
2. Explored data structure and data types
3. Identified missing values and anomalies
4. Visualized distributions using histograms and boxplots
5. Analyzed relationships using correlation heatmaps
6. Tested hypotheses using scatter plots

## 📊 Output Visualizations
- Histograms
- Boxplots
- Correlation Heatmap
- Scatter Plot
